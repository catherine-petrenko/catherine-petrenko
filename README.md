# Catherine Petrenko — Portfolio

Minimalist portfolio site showcasing my system-thinking approach to project and product work.  
Built as a static site with HTML, CSS, and JSON-driven multilingual content.

---

## Features

- English / Spanish / Russian content via JSON
- Smooth language & theme switching (dark / light)
- Clean, responsive layout with modern typography
- Structured presentation of skills, experience, and philosophy
- Scalable design: easy to add languages or content blocks

---

Project & Product Manager with 10+ years in IT and e-commerce.  
I design systems that keep working even when people rest — clarity, documentation, and thoughtful process design are my tools.

## Project Stage

The site is currently in **PreMVP**:

- Static architecture on GitHub Pages
- Single-page “About” experience
- JSON-based multilingual content (EN / ES / RU)
- Early SEO, accessibility, and layout experiments
- Automated tests and CI/CD via GitHub Actions (tests on push/PR → deploy to GitHub Pages)

The focus at this stage is to validate the static setup, delivery pipeline, and single-page experience before calling the first version “good enough to share without a work-in-progress disclaimer”.
